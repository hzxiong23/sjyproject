Abstract

Interactive joint audio-video generation requires users to schedule independently timed events and introduce new instructions as generation proceeds. Existing global conditioning and segment-level prompt switching offer limited support for dynamically arriving controls with asynchronous, overlapping intervals.

TempoTrack maps structured event instructions to blockwise causal generation through Hierarchical Context Routing, and combines causal adaptation with few-step self-forcing distribution matching. The resulting framework supports online multi-track control while preserving identity and audiovisual synchronization.

Motivation

Streaming generation needs control over individual events, not only a single description for the entire sequence or a replacement prompt for each chunk.

Structured multi-track inputs

TempoTrack separates persistent identity and scene conditions from time-localized face, body, music, and speech instructions, each with an independent target interval.

Online prompt admission

An online prompt queue selects the instructions relevant to each causal window and admits newly received controls at the next block boundary.

Shared physical timeline

Temporal Attention Bias aligns instruction intervals with audio and video query positions, supporting overlapping events while maintaining audiovisual coordination.

Method

Hierarchical Context Routing bridges event-level instructions and blockwise generation: coarse admission selects the relevant instructions for each causal window, while fine routing aligns their influence inside the block.

Temporal Attention Bias

A timestamp-dependent Gaussian bias aligns instruction intervals with audio and video query positions on a shared physical timeline.

Stage 1

Bidirectional HCR learning

Full-sequence audio-video training teaches high-quality generation and temporally grounded control. The pretrained backbone remains frozen while LoRA adapters learn the task.

Stage 2

Causal adaptation

Block-causal masking and teacher forcing adapt the model for streaming inference, conditioning each noisy block on preceding clean ground-truth blocks.

Stage 3

Self-forcing DMD

A pretrained distillation LoRA supplies few-step initialization. An additional DMD LoRA is optimized on self-generated histories while the causal and distillation components stay frozen.

Streaming inference

Sliding-window context bounds history length, while a retained first-block attention sink and RoPE repositioning support identity consistency and audiovisual coordination over time.
